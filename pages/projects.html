Python VLM Evaluation Synthetic Data Generation Temporal Reasoning Model Scaling Analysis

References:

Problem: Assessing video-language model robustness requires systematic, stress-tested benchmarks, but standard datasets lack parameterized control over event frequency, clutter, or object scale.

What I did: Developed a parametric capability profiling framework to evaluate video-language models by systematically varying event frequency, event count, temporal span, clutter, and object scale. Created controlled temporal and spatial reasoning tasks, including State Transition, Blinking, Bouncing Ball, and Domino Counting, with deterministic executable traces for ground-truth validation. PlanForge: Executable Planner Generation from Natural Language

Affiliation: University of Maryland, Baltimore County (UMBC) (May 2025 - Present)

Developed an Architect–Builder–Runner framework that converts natural-language planning problems into executable solver programs rather than direct textual plans.

Python LLM Agents Planning Code Generation Search Algorithms Verification Natural-Language Planning

References:

Problem: Traditional direct LLM plan generation from natural language is highly brittle, unverified, and generalizes poorly to multi-constraint tasks with multiple valid solutions.

Architecture and Workflow:

  • Architect Stage: Infers state representations, function decompositions, algorithmic strategies, and verification logic from natural-language planning problems without a fixed schema or prescribed search algorithm.
  • Builder Pipeline: Converts solver designs into executable code, including parsing, constraint checking, search/solving logic, helper functions, and iterative code–test–fix repair.
  • Runner Execution: Implements a deterministic runner that executes generated solvers and accepts only verified outputs: a valid executable plan, a no-plan verdict for unreachable goals, or a failure signal.

Impact and Results: Evaluated PlanForge on ACPBench, Tower of Hanoi, Frogs Jumping, and NaturalPlan, showing vastly improved execution-grounded planning over direct LLM plan generation. Achieved a 100% success rate on NaturalPlan trip planning, meeting planning, and calendar scheduling, demonstrating flawless transfer to multi-constraint planning tasks with multiple valid solutions.

Multi-Step Reasoning Using Process Reward Models

Affiliation: University of Maryland, College Park (UMD) (Jul 2025 - Aug 2025)

Evaluated process supervision in mathematical reasoning by training step-level Process Reward Models (PRMs) versus outcome-only verifiers.

PRMs GSM8K Step-Level Verifiers Python

References:

Problem: Outcome-only supervision in math reasoning rewards the final answer but ignores the quality of intermediate steps. This leads to brittle chains of thought, unnecessarily long solutions, and failures that are hard to diagnose or correct. Our hypothesis is that using PRM would produce more correct steps.

What I built: An end-to-end PRM pipeline that generates multi-step trajectories, assigns weak step-level labels using verifier/self-consistency signals, and uses that score at inference for PRM-guided answers.

Impact and Results: Experimenting on GSM8K PRM guidance underperformed both baselines across held out sets. Our initial results demonstrates that Majority voting was consistently strongest with a 92% accuracy compared to PRM with a 68% accuracy.
