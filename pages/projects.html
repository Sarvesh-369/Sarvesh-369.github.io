The Low-Frequency Trap: Video–Language Models Fail at Simple Event Bookkeeping

Affiliation: University of Maryland, College Park (UMD) (Sep 2025 - Jul 2026)

Created a parametric evaluation framework to systematically map video model performance across variations in frequency, count, temporal span, clutter, and scale.

Python VLM Evaluation Synthetic Data Generation Temporal Reasoning Model Scaling Analysis

References:

Problem: Assessing video-language model robustness requires systematic, stress-tested benchmarks, but standard datasets lack parameterized control over event frequency, clutter, or object scale.

What I did: Developed a parametric capability profiling framework to evaluate video-language models by systematically varying event frequency, event count, temporal span, clutter, and object scale. Created controlled temporal and spatial reasoning tasks, including State Transition, Blinking, Bouncing Ball, and Domino Counting, with deterministic executable traces for ground-truth validation. Benchmarked Qwen3-VL, Molmo2, and InternVL3.5 models across parameterized difficulty grids using exact-match accuracy across randomized seeds.

Impact and Results: Identified a low-frequency temporal reasoning trap, where models failed to count simple events beyond small thresholds even when events were slow and visually distinct. Showed that scaling model size from 8B to 235B parameters improved average accuracy but did not meaningfully expand the temporal success region, suggesting scale alone is insufficient for robust temporal reasoning. (Under Review at AAAI, 2027)

PlanForge: Executable Planner Generation from Natural Language

Affiliation: University of Maryland, Baltimore County (UMBC) (May 2025 - Present)

Developed an Architect–Builder–Runner framework that converts natural-language planning problems into executable solver programs rather than direct textual plans.

Python LLM Agents Planning Code Generation Search Algorithms Verification Natural-Language Planning

References:

Problem: Traditional direct LLM plan generation from natural language is highly brittle, unverified, and generalizes poorly to multi-constraint tasks with multiple valid solutions.

Architecture and Workflow: Architect Stage: Infers state representations, function decompositions, algorithmic strategies, and verification logic from natural-language planning problems without a fixed schema or prescribed search algorithm. Builder Pipeline: Converts solver designs into executable code, including parsing, constraint checking, search/solving logic, helper functions, and iterative code–test–fix repair. Runner Execution: Implements a deterministic runner that executes generated solvers and accepts only verified outputs: a valid executable plan, a no-plan verdict for unreachable goals, or a failure signal.

Impact and Results: Evaluated PlanForge on ACPBench, Tower of Hanoi, Frogs Jumping, and NaturalPlan, showing vastly improved execution-grounded planning over direct LLM plan generation. Achieved a 100% success rate on NaturalPlan trip planning, meeting planning, and calendar scheduling, demonstrating flawless transfer to multi-constraint planning tasks with multiple valid solutions. (Under Review at AAAI, 2027)

Frames2LoRA: Parametric Video Internalization for Vision-Language Models

Affiliation: University of Maryland, College Park (UMD) (Mar 2026 - May 2026)

Introduced Frames2LoRA, a method for parametric video internalization where a perceiver hypernetwork generates a Low-Rank Adaptation (LoRA) adapter directly from a video's intermediate representations in a single forward pass, enabling video question answering and summarization with zero visual tokens at query time.

SmolVLM2 LoRA Hypernetworks PyTorch Python

References:

Problem: Processing videos in vision-language models (VLMs) is extremely token-heavy and computationally expensive. Concatenating hundreds of visual tokens per frame into the VLM's context window increases latency, scales up query time-to-first-token (TTFT), and limits the model's ability to process long-video sequences effectively without context window degeneration.

What I did: Introduced Frames2LoRA, a method for parametric video internalization. Designed a perceiver hypernetwork that runs layer-by-layer alongside a frozen VLM to ingest intermediate video representations and predict Low-Rank Adaptation (LoRA) weight adapters in a single forward pass, entirely bypassing iterative gradient-based training. Implemented training on SmolVLM2 (500M and 2.2B) for video question answering, summarization, and captioning.

Impact and Results: Achieved statistical non-inferiority to standard in-context video inference on 5 captioning and 7 of 8 QA benchmarks, while reducing visual token load at query time by up to 1,500× and query TTFT by 6× to 80×. Demonstrated stability up to 1,024 frames and showed that independently generated adapters can compose in rank space for chunked long-video internalization. (Under Review at EMNLP, 2026)

Multi-Step Reasoning Using Process Reward Models

Affiliation: University of Maryland, College Park (UMD) (Jul 2025 - Aug 2025)

Evaluated process supervision in mathematical reasoning by training step-level Process Reward Models (PRMs) versus outcome-only verifiers.

PRMs GSM8K Step-Level Verifiers Python

References:

Problem: Outcome-only supervision in math reasoning rewards the final answer but ignores the quality of intermediate steps. This leads to brittle chains of thought, unnecessarily long solutions, and failures that are hard to diagnose or correct. Our hypothesis is that using PRM would produce more correct steps.

What I built: An end-to-end PRM pipeline that generates multi-step trajectories, assigns weak step-level labels using verifier/self-consistency signals, and uses that score at inference for PRM-guided answers.

Impact and Results: Experimenting on GSM8K PRM guidance underperformed both baselines across held out sets. Our initial results demonstrates that Majority voting was consistently strongest with a 92% accuracy compared to PRM with a 68% accuracy.

Large Language Models for Code Deobfuscation

Affiliation: University of Maryland, Baltimore County (UMBC) (Feb 2025 - May 2025)

Automated LLVM-IR low-level deobfuscation under Bogus Control Flow (BCF) and Control Flow Flattening (CFF) using reasoner LLMs.

LLVM-IR Chain of Thought Deobfuscation Python

References:

Problem: Automating deobfuscation of low level LLVM-IR is difficult with existing tools that struggle under Bogus Control Flow and Control Flow Flattening, and there is no standardized AI evaluation for this setting.

What I did: Led the AI modeling and evaluation track. Designed Chain of Thought procedural prompts with global variable tracing. Built an LLVM-IR analysis module to extract basic blocks and control flow graphs and to compute Cyclomatic Complexity and instruction counts. Implemented an adjustment step to normalize identifiers for fair Levenshtein similarity. Created an evaluation harness using Code Reduction, Levenshtein Similarity, and Cyclomatic Complexity and benchmarked four reasoner models on O-LLVM obfuscations.

Impact and Results: Established a 36 sample LLVM-IR benchmark across BCF, CFF, and BCF-CFF. Best model achieved 76.9% code reduction and 85% similarity on BCF-CFF with Cyclomatic Complexity reduced from 91 to 13.5 (85%). (Published at WoRMA, 2026)
